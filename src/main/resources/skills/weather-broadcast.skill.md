# 天气语音播报工作流

当用户要求用语音播报天气时，按以下步骤：

1. **查询天气**：调用 `get_weather`，传入城市名
2. **整理文本**：将天气数据（温度、湿度、风力等）整理成自然口语化的一段话
3. **转语音**：调用 `text_to_speech`，传入整理好的文本
4. **完成**：语音发送后直接结束，**不需要再回复文字**

注意事项：
- 天气数据来自高德 API，返回温度/湿度/风力/天气状况
- 语音文本要口语化，加上语气词让播报更自然
- text_to_speech 是终端工具，执行完对话结束
