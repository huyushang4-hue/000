# 附近餐厅搜索工作流

当用户要搜索附近美食时：

1. **搜索餐厅**：调用 `search_nearby_restaurants`，可传 city 和 keywords
2. **整理结果**：将返回的餐厅列表（名称、评分、地址）按评分排序
3. **回复用户**：用简洁清晰的方式列出 TOP 3-5 推荐

注意事项：
- 如果用户没指定城市，先问一下
- 如果用户说"附近"但没有授权位置，让用户说城市名
- 关键词如：火锅、烧烤、日料、川菜
