# 信息监控工作流

当需要持续关注某个话题的最新动态时，按以下步骤：

## 首次执行
1. 调用 `get_realtime_info` 搜索指定关键词
2. 整理搜索结果，列出 TOP 5 关键信息
3. 保留完整结果供下次对比

## 后续执行
1. 调用 `get_realtime_info` 用相同关键词重新搜索
2. 与"上次搜索的结果"逐一对比
3. **只报告新增或重大变化**的内容
4. 如果和上次基本一样，直接回复"暂无变化"（不要展开内容）
5. 将本次结果保存供下次对比

## 关键词建议
- 使用明确的技术词汇（如"鸿蒙开发招聘"而非"找工作"）
- 如果搜索结果太少，尝试用同义词重新搜索
- 如果是周期性任务（如"每小时"），尽量保持关键词一致以便对比

## 通知格式
有变化时用简洁格式：
```
🔔 [主题] 更新
• 新内容1
• 新内容2
```
